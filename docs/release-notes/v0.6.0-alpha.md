# Kinfold v0.6.0-alpha

Operability release: per-device relay bandwidth limits, live device status,
a macOS service, safer administrative writes, full user guides in English
and German, and an open source license. Builds on v0.5.0-alpha; not
independently audited — use it for evaluation and non-critical networks.

## Upgrade notes

- No protocol or state format change: v0.6 controllers and clients work
  with v0.5 ones. Updating everything together is still recommended.
- `kinfold status` now accepts only `-credential`. Scripts that passed
  `run` options such as `-interface` to `status` must drop them.
- `add-peer`, `approve`, `rotate-peer` and `replica-add` now refuse an
  existing output file or a missing output directory before they change the
  controller state.

## New

- **Relay bandwidth limit (#96).** `serve -relay-rate 2M` limits what each
  device sends through the relay, summed over all its sessions (token
  bucket, `-relay-burst`, k/M/G suffixes). Throttling slows the stream down
  and never drops data. Off by default. The metric
  `kinfold_relay_throttle_delay_milliseconds_total{peer}` shows who hits
  the limit.
- **Live device status (#97).** The controller exports
  `kinfold_device_last_seen_timestamp_seconds{peer}` and
  `kinfold_device_relay_endpoints{peer}`, so you can see which devices are
  online and relaying.
- **macOS service (#98).** `packaging/launchd/kinfold-client.plist` runs
  the macOS client as a launch daemon and ships with the release. IPv6 on
  macOS is now tested end to end.
- **User guides (#108).** Every release, back to v0.1-copilot, has a full
  user guide in English and German (`docs/user-guide/`). This release
  attaches its guides as `kinfold-v0.6.0-alpha-user-guide-en.md` and `-de.md`.
- **License (#114).** Kinfold is now licensed under the GNU Affero General
  Public License v3 (`AGPL-3.0-only`).

## Fixes

- Administrative commands write the controller state before the credential
  or certificate file, so a certificate can no longer exist outside the
  member list (#99).
- `status -h` no longer lists tunnel options, and the help names macOS for
  `run` (#109).
- Documentation that predated tokens, the direct path and standby
  controllers was corrected, including a restore note for pre-v0.4 backups
  (#100, #109).
- A flaky test of the direct path was fixed (#105).

## Quality assurance

An independent review of all changes before the release found no high or
medium issues and five low ones, all fixed (#117): limit values that would
silently switch the bandwidth limit off, state of removed devices that was
never freed, and throttled relay sessions that outlived a superseded
connection. A second review of these fixes found that revocations did not
end such sessions either; that was fixed too. Race tests, five fuzz
targets, the Docker integration test (14 scenarios, with the controller
running under a relay limit) and the macOS end-to-end test over IPv4 and
IPv6 pass.
