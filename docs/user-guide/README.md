# User guides / Benutzerhandbücher

Every Kinfold release has a full user guide in English and German that
describes exactly the features of that version (D-038). Use the guide that
matches the version you run.

Jede Kinfold-Version hat ein vollständiges Benutzerhandbuch auf Englisch und
Deutsch, das genau den Funktionsumfang dieser Version beschreibt. Verwenden
Sie das Handbuch passend zur eingesetzten Version.

| v0.5.0-alpha | [User guide](en/v0.5.0-alpha.md) | [Benutzerhandbuch](de/v0.5.0-alpha.md) | Standby controller, macOS client |
